### 5.2 Pages の切り替え手順

`.github/workflows/pages.yml` は **`main` への push でだけ動く**（`v2` では動かない）。Source を切り替えないうちは、`main` に入れても何も配信されない。

1. `v2` を確認して、問題なければ `main` にマージする準備をする
2. GitHub の `wada3333/portfolio` → **Settings → Pages → Build and deployment → Source** を「Deploy from a branch」から **「GitHub Actions」** に切り替える
3. すぐに `main` へマージして push する（切り替えてからワークフローが成功するまでの数分間、サイトが 404 になる可能性がある。続けて行うのが安全）
4. **Actions タブ** で `Pages` が緑になるのを待つ。失敗したときは赤い行を開いて理由を見る（`workflow_dispatch` で手動でも動かせる）
5. 公開後に確かめる:

```bash
# 公開するもの（すべて 200）
for p in "" assets/og.png assets/js/app.js assets/images/pkg-line.webp assets/fonts/OFL.txt; do
  printf "%s  /%s\n" "$(curl -s -o /dev/null -w '%{http_code}' https://wada3333.github.io/portfolio/$p)" "$p"; done
# 公開してはいけないもの（すべて 404）
for p in portfolio-lp-spec.md docs/implementation-notes.md tools/check.mjs assets/og-bg.png assets/fonts/charset.txt; do
  printf "%s  /%s\n" "$(curl -s -o /dev/null -w '%{http_code}' https://wada3333.github.io/portfolio/$p)" "$p"; done
```

6. LC・CW のプロフィールと提案文のリンクを貼り替える
   - ランサーズ: `https://wada3333.github.io/portfolio/?from=lc`
   - クラウドワークス: `https://wada3333.github.io/portfolio/?from=cw`
7. 公開URLで Lighthouse を測り直し、OGP をX・Facebook などのデバッガーで確かめる（`og.png?v=3` に変えてあるので、古い画像のキャッシュは避けられる）
